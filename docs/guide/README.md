# Guide to RhapsoSAT 1.0 experimental

A short tour for readers with no background in mathematics or programming.
Each page takes a few minutes.

1. [What it does](01-what-it-does.md) — the puzzle, in plain words.
2. [Trying it](02-trying-it.md) — the demo page and the command line.
3. [How it works](03-how-it-works.md) — the idea that makes it fast.
4. [Checking answers](04-checking-answers.md) — why you do not have to trust it.
5. [Words used](05-words-used.md) — a small glossary.
6. [Going deeper](06-going-deeper.md) — optional: where the technical material is.

The same words are used throughout: a **text** is the unknown string, a
**position** is one place in it (counted from 1 in the solver's reports),
and a **rule** is one of the three kinds of statement the solver accepts.
